# Clash Royale Stats Tracker

A player and clan stats tracker for Clash Royale, powered by the official Clash Royale API.

## Features
- Look up player stats (trophies, level, cards, battle history, etc.)
- View clan info and member stats
- Data fetched live from the Clash Royale API

## Tech Stack
- **Backend:** Python — calls the Clash Royale API and serves data
- **Frontend:** JavaScript, CSS

## Project Structure
```
backend/     # Python API client / server logic
Frontend/    # UI (JS, CSS)
```

## Setup

1. Clone the repo
   ```bash
   git clone https://github.com/Rishit-Sinha10/clash_royale.git
   cd clash_royale
   ```
2. Get a Clash Royale API key from [developer.clashroyale.com](https://developer.clashroyale.com)
3. Install backend dependencies and add your API key (e.g. via a `.env` file)
4. Run the backend, then open the frontend
